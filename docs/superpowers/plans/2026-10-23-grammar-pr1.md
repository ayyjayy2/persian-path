# Grammar PR 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each daily lesson gets a verb conjugation card and a "Grammar" practice activity. The first grammar page, Present tense, opens from the learning path and from a new Grammar list on the Learn page.

**Architecture:** No build step. Data goes in `learn-data.js`:
- `PERSONS`: the six persons
- `CONJ`: one verb per lesson
- `GRAMMAR`: topic pages

`app.js` turns the data into view-model fields:
- `conjTable()` builds a register-aware table
- a new exercise kind, `grammar`, reuses the multiple-choice UI
- a new `grammar` route

`view.js` renders the tables with one shared `verbTable()` helper, used by the lesson card and the grammar page.

**Tech Stack:** Preact + htm (vendored), plain ES modules. There's no test runner, so checks are Node one-liners against `learn-data.js` plus browser checks on the local server (port 8080) with audio muted.

**Spec:** `docs/superpowers/specs/2026-10-23-grammar-design.md`

- [ ] **Step 1: Add `conjTable()` next to `disp()`**

`conjTable()` returns a lesson's verb in the current register:

```js
  conjTable(lessonId) {
    const c = this.D.CONJ[lessonId]; if (!c) return null;
    const written = this.prefs().register === 'written';
    return { inf: c.inf, infFa: c.infFa, en: c.en, rows: c.rows.map(([sp, spLat, wr, wrLat, en], i) => {
      const [who, whoLat, whoFa] = this.D.PERSONS[i];
      return { who, whoLat, whoFa, fa: written ? wr : sp, lat: written ? wrLat : spLat, en };
    }) };
  }
```
