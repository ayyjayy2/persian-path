# Sync All User Data, Round 1: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sync a signed-in learner's review schedule, mistakes, settings, page-seen flags, today's XP and My words list (no pictures) across devices through a new `profiles.app_state` column.

**Architecture:** A new pure module, `sync.js`, exports `mergeState(local, remote)`. It holds every conflict rule and is tested in Node. `app.js` stamps "last changed" times where the data changes, pushes the synced fields as `app_state` with the existing upsert, and merges them in `pullRemote`.

**Tech Stack:** Preact + htm with no build step, ES modules, supabase-js 2 (vendored), Node 18+ `node:assert` for tests.

**Spec:** `docs/superpowers/specs/2026-10-23-sync-design.md`

**Branch:** `PER-41-sync`. This is a batched release: commit each task here and push only when the user says yes. Merge to main only when the user says to ship, **after** they have run the SQL in Task 6.

```js
// Merges the progress two devices hold for the same account. Pure: no DOM, Supabase or Preact,
// so Node can test it (scripts/test-sync.mjs). Rules: docs/superpowers/specs/2026-10-23-sync-design.md

// State keys pushed to profiles.app_state
export const SYNCED = ['srs', 'mistakes', 'mistakeAt', 'prefs', 'prefsU', 'scriptSeen', 'vowelsSeen', 'grammarSeen',
  'todayXp', 'lastPlayedDate', 'myWords', 'deletedWords'];

const MAX_MISTAKES = 40;
const u = x => (x && x.u) || 0;
const day = d => (d ? new Date(d).getTime() || 0 : 0);

// Per key, the later of two timestamped entries; a tie keeps a (local)
function newer(a = {}, b = {}) {
  const out = { ...a };
  Object.entries(b).forEach(([k, v]) => { if (!(k in out) || u(v) > u(out[k])) out[k] = v; });
  return out;
}

export function mergeState(local, remote) {
  const L = local || {}, R = remote || {};

  const deletedWords = { ...(L.deletedWords || {}) };
  Object.entries(R.deletedWords || {}).forEach(([id, t]) => { if (!(deletedWords[id] >= t)) deletedWords[id] = t; });

  const byId = {};
  [...(L.myWords || []), ...(R.myWords || [])].forEach(w => { if (!byId[w.id] || u(w) > u(byId[w.id])) byId[w.id] = w; });
  const myWords = Object.values(byId).filter(w => !(deletedWords[w.id] >= u(w))).sort((a, b) => (b.created || 0) - (a.created || 0));
  const kept = new Set(myWords.map(w => w.id));
  const gone = k => k.startsWith('my:') && deletedWords[k.slice(3)] != null && !kept.has(k.slice(3));

  const srs = newer(L.srs, R.srs);
  Object.keys(srs).forEach(k => { if (gone(k)) delete srs[k]; });

  const at = { ...(L.mistakeAt || {}) };
  Object.entries(R.mistakeAt || {}).forEach(([k, t]) => { if (!(at[k] >= t)) at[k] = t; });
  const mistakes = [...new Set([...(L.mistakes || []), ...(R.mistakes || [])])].filter(k => !gone(k))
    .sort((a, b) => (at[b] || 0) - (at[a] || 0)).slice(0, MAX_MISTAKES);
  const mistakeAt = {}; mistakes.forEach(k => { if (at[k] != null) mistakeAt[k] = at[k]; });

  const remotePrefs = (R.prefsU || 0) > (L.prefsU || 0);

  const sameDay = L.lastPlayedDate === R.lastPlayedDate;
  const todayXp = sameDay ? Math.max(L.todayXp || 0, R.todayXp || 0)
    : day(R.lastPlayedDate) > day(L.lastPlayedDate) ? (R.todayXp || 0) : (L.todayXp || 0);

  return {
    srs, mistakes, mistakeAt, myWords, deletedWords,
    prefs: remotePrefs ? (R.prefs || {}) : (L.prefs || {}), prefsU: Math.max(L.prefsU || 0, R.prefsU || 0),
    scriptSeen: !!(L.scriptSeen || R.scriptSeen), vowelsSeen: !!(L.vowelsSeen || R.vowelsSeen),
    grammarSeen: { ...(L.grammarSeen || {}), ...(R.grammarSeen || {}) },
    todayXp,
  };
}
```

Replace everything from `  // ---------- account sync ----------` down to the closing `  }` of `pushRemote` with:

```js
  // ---------- account sync ----------
  // profiles keeps the v1 columns (xp, streak, last_played_date, completed_lessons) plus app_state,
  // which holds everything else in SYNCED. sync.js decides how two devices' copies merge.
  async pullRemote(user) {
    const { data, error } = await sb.from('profiles').select('*').eq('id', user.id).maybeSingle();
    if (error) { console.warn('Sync failed', error.message); return; }
    if (data) {
      this.setState(s => {
        const progress = { ...(data.completed_lessons || {}) };
        Object.entries(s.progress).forEach(([id, p]) => { progress[id] = typeof p === 'object' ? { ...(progress[id] || {}), ...p } : p; });
        const remoteNewer = data.last_played_date && (!s.lastPlayedDate || new Date(data.last_played_date) > new Date(s.lastPlayedDate));
        const merged = mergeState(s, { ...(data.app_state || {}), lastPlayedDate: data.last_played_date });
        return rollDay({ ...s, ...merged, progress, xp: Math.max(s.xp, data.xp || 0),
          streak: remoteNewer ? (data.streak || 0) : s.streak, lastPlayedDate: remoteNewer ? data.last_played_date : s.lastPlayedDate });
      }, () => this.loadImgs());
    }
    this.pushRemote();
  }
  pushRemote() {
    const s = this.state; if (!sb || !s.user || !navigator.onLine) return;
    clearTimeout(this._pushT);
    this._pushT = setTimeout(() => {
      const st = this.state, app_state = {}; SYNCED.forEach(k => { app_state[k] = st[k]; });
      sb.from('profiles').upsert({ id: st.user.id, xp: st.xp, streak: st.streak, last_played_date: st.lastPlayedDate,
        completed_lessons: st.progress, app_state, updated_at: new Date().toISOString() }).then(({ error }) => { if (error) console.warn('Sync failed', error.message); });
    }, 600);
  }
```

Notes for the implementer:
- `pullRemote` passes `data.last_played_date` into the remote side, so the `todayXp` rule compares the same dates the streak rule uses.
- `loadImgs` runs after the merge, so words restored from the account show pictures that already exist in this device's IndexedDB.
- The `if (error) … return` is new. Before, a failed select fell through and pushed, which could overwrite the account with this device's data.
